# Memoir Notes

A simple note-taking app built with Next.js and React. Sign in with a Gmail
address and a password longer than six characters, then create and delete notes
in your browser.

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to use the app.

## Features

- Login form with email and password validation
- Inline validation messages below the login button
- Create and delete notes
- Notes saved in browser local storage
- Session-based demo login with a logout button

This is a front-end demo, not production authentication. The login does not
verify credentials with a server.

## Available scripts

- `npm run dev` - start the development server
- `npm run lint` - run ESLint
- `npm run build` - create a production build
- `npm run start` - start the production server
